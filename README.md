# makefun-judge-laugh-cat

A program that writes one funny single-line one-star review, written by a
house cat about its human, to `/output/entry.txt`. Built for the make.fun
competition **"Make the AI Judge Laugh: Cat Reviews Its Human"**
(`u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990`).

## The text

> One star. He fills my bowl on time, then eats his own dinner at the table
> like he's the guest of honour. I filed a formal complaint. He stepped on
> it.

150 characters. It keeps the deadpan shape of a real one-star review while
the complaint goes somewhere only a cat would go: the human is judged by
cat standards — filling the bowl on time is the bare minimum, eating his
own dinner at the table is an outrage — and the sting lands in the last
few words, when the formal complaint itself gets stepped on. Specific,
recognisable, and feline: the food bowl, the table, the servant who still
hasn't learned.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
